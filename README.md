# 실험실 계산기 (Lab Calculator)

미생물 실험에서 자주 쓰는 계산 3가지를 브라우저에서 바로 하는 단일 HTML 파일 도구.
설치 불필요, 외부 라이브러리 없음.

**바로 쓰기 → https://j-hy-04.github.io/lab-calculator/** (PC·폰 브라우저 모두 가능)

## 기능

| 계산 | 공식 | 용도 |
|---|---|---|
| **희석 (Dilution)** | C₁V₁ = C₂V₂ | stock 용액에서 원하는 농도·부피 만들기 |
| **몰농도 ↔ 질량 농도** | 질량농도(g/L) = 몰농도(mol/L) × 분자량(g/mol) | 시약 몇 g 달지 계산 |
| **OD₆₀₀ → 세균 수 추정** | cells/mL ≈ OD₆₀₀ × 환산계수 | 형질전환·접종량 대략 계산 |

## 사용법

- **온라인**: 위 링크(https://j-hy-04.github.io/lab-calculator/) 접속. 폰에서도 그대로 동작.
- **오프라인**: `index.html` 파일을 내려받아 웹 브라우저로 연다 (더블클릭).

사용 순서:

1. 각 카드에 값을 넣고 **계산** 버튼을 누른다.
2. 희석 계산은 4칸 중 **모르는 1칸을 비워두면** 그 값을 구해 준다.

## 주의

- **OD₆₀₀ 환산계수**는 균주(strain)·분광광도계 기종·큐벳 광경로에 따라 달라진다.
  기본값 `8e8` (8×10⁸ cells/mL per OD₆₀₀)은 *E. coli* 대상으로 흔히 인용되는 대략치이며
  (보고에 따라 5×10⁸ ~ 1×10⁹), 정확한 값은 희석 도말(serial dilution plating)로 직접 보정해야 한다.
- 농도 단위는 입력끼리 맞춰서 넣는다 (예: C₁·C₂ 둘 다 µg/mL).
- 계산 결과는 참고용. 중요한 실험은 직접 검산할 것.

## 사용 예시

**1. 희석** — 1000 µg/mL antibiotic stock으로 20 mL 배지를 50 µg/mL로 만들기
→ C₁=1000, C₂=50, V₂=20, V₁ 칸은 비움 → **V₁ = 1 mL** (stock 1 mL + 배지 19 mL)

**2. 몰농도 → 질량** — 0.5 M NaCl 용액 500 mL 만들기 (MW 58.44)
→ 몰농도=0.5, 분자량=58.44, 만들 부피=500 → **NaCl 14.61 g 필요**

**3. OD₆₀₀ → 세균 수** — *E. coli* 배양액 5 mL, OD₆₀₀ 0.6 측정 (환산계수 8e8)
→ **≈ 4.8×10⁸ cells/mL, 총 ≈ 2.4×10⁹ cells** (환산계수는 본인 조건으로 보정 필요)
